CLIメタコマンド

コマンド用途使う場面
/permissions承認、読み取り、書き込み、ネットワークなどの許可範囲を調整作業中に安全側へ寄せる、または承認回数を減らす
/modelモデルや推論設定を変更軽い調査と重い設計、レビューで使い分ける
/fast利用可能な場合にFast tierを切り替え応答速度を優先したい短い作業
/plan実装前に計画を出すモードへ切り替え大きめの変更、危険な変更、方針確認が必要な作業
/goal長めのタスク目標を設定、確認、停止、再開複数ターンにまたがる調査や改修
/status現在のセッション状態を確認モデル、権限、作業状態を見直す
/compact長い会話を要約してコンテキストを節約長時間作業で履歴が重くなったとき
/clear表示と会話をリセットして新しく始める前提を切り替えて別作業に移る
/new同じCLI内で新しい会話を開始同じリポジトリで別の作業に切り替える
/resume保存済み会話を一覧から再開前に中断した作業へ戻る
/fork現在の会話を新しいスレッドへ分岐今の文脈を残したまま別案を試す
/rollback直前の会話ターンを取り消す送った指示やその応答を履歴から戻したいとき
/redo/rollback で取り消したターンを復元直前の取り消しをやはり戻したいとき
/side / /btw一時的な横道の会話を開始本筋の履歴を崩さず短い確認をする
/copy直近のCodex出力をコピー計画、レビュー結果、説明文を転記する
/exit / /quitCodex CLIを終了作業を終える

セッション管理

コマンド用途使う場面
codex新しい対話セッションを開始完全に新しい作業を始める
codex resume過去セッションを一覧から再開中断した作業、過去の文脈へ戻る
codex resume --last直近セッションを即再開さっきの続きに戻る
codex resume --all作業ディレクトリに関係なく全セッションから選ぶ別リポジトリで使った会話も探す
codex fork過去セッションを分岐して新しいセッションにする同じ前提から別案を試す
codex archive <id>保存済みセッションをアーカイブ一覧を整理する
codex unarchive <id>アーカイブ済みセッションを戻す過去作業を再び参照する
/rollback / /redo現在のセッション内で直前ターンを取り消し、取り消しを戻す会話ログ単位で undo / redo したいとき
git worktree add ../repo-task main作業ツリーも分離して別セッションを開始同じリポジトリで複数タスクを並行し、ファイル衝突を避ける

文脈、拡張、連携

コマンド用途使う場面
/mentionファイルやフォルダを会話へ添付特定ファイルを必ず見てほしいとき
/ideIDEで開いているファイルや選択範囲を取り込むエディタ上の文脈を説明せず渡す
/pluginsPluginの一覧、詳細、インストール、有効化を管理外部連携や配布済みワークフローを追加する
/skills利用可能なSkillを確認、選択レビュー、ドキュメント更新、リリース作業などの定型手順を使う
@plugin-namePluginやPlugin内のSkillを明示的に呼び出すどの拡張を使うかCodexに任せたくないとき
/appsアプリ、コネクタをプロンプトへ追加Google Drive、Slack、Gmailなどの外部データを使う
/mcp設定済みMCPツールを確認外部ツールや社内システム連携の状態を見る
/hooksライフサイクルフックを確認、信頼、無効化コマンド実行や編集前後の自動処理を点検する
/initAGENTS.md の雛形を生成リポジトリ固有の恒久ルールを作り始める
/memoriesメモリ利用や生成を設定個人向けの継続的な文脈を調整する

実行中の操作

コマンド用途使う場面
/diffGit差分と未追跡ファイルを表示Codexの編集内容をコミット前に確認する
/approve自動レビューで拒否された操作を一度だけ再承認安全性を確認済みのコマンドを再試行する
/agentサブエージェントのスレッドを切り替え分担した調査や検証結果を確認する
/psバックグラウンド端末の状態を表示長時間コマンドの出力や進捗を見る
/stopバックグラウンド端末を停止不要なサーバーや長い検証を止める
/feedbackログを添えてフィードバックを送るCodex自体の不具合を報告する
/logoutサインアウト共有端末や認証切り替え時

入力、表示、実験機能

コマンド用途使う場面
/keymapTUIのキーボードショートカットを確認、変更よく使う操作を自分のキー割り当てに寄せる
/vim入力欄のVimモードを切り替えVim操作でプロンプトを編集したいとき
/raw生の入力や出力を扱うモードを切り替え整形を抑えて内容を渡したい、確認したいとき
/experimental実験的な機能を切り替えサブエージェントなど任意機能を試す
/sandbox-add-read-dir追加ディレクトリの読み取り許可を付与Windowsで作業ルート外の絶対パスを読む必要があるとき

レビュー観点

  • 既存仕様、API、DBスキーマとの互換性
  • 入力値検証、権限チェック、認可漏れ
  • 例外時、空データ時、タイムアウト時の挙動
  • テストの有無と失敗時の切り分けやすさ
  • 不要な依存追加、過剰な抽象化
  • パフォーマンス悪化、N+1、不要な再描画
  • ログ、個人情報、秘密情報の扱い
  • ドキュメントや設定例の更新漏れ

トラブル時の切り分け

症状確認すること
Skillが出てこないSKILL.md の場所、name と description、Codex再起動の要否
Pluginが使えないインストール済みか、有効化されているか、外部サービス認証が済んでいるか
コマンドが実行できないサンドボックス、承認モード、依存関係、作業ディレクトリ
回答がプロジェクトに合わないAGENTS.md に規約、コマンド、禁止事項を追加する
